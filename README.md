# Philadelphia Civic Wiki

A plain-English reference to how Philadelphia politics, city departments, unions, authorities and civic
organizations work. 166 articles, 10 topic portals, glossary, references and a department directory.

**Read it:** https://thumpersecure.github.io/philly-civic-wiki/

Static retro-Monobook site: no JavaScript required, no trackers, no cookies. General civic education, not legal advice.
Facts are current to about October 2026; verify names, deadlines and figures with the agency.

Build: `python3 build.py` turns `articles/*.html` fragments into `wiki/`. Corrections welcome via issues.
